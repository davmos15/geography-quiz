- `vinson-massif`: selected from `geo_points_50m` (NE featurecla `mountain`, a point), but Wikidata's P31 is `Q46831` (mountain range), so this entry's `type` is `range`, not `peak`.

## Alias curation

Wikidata's raw English `skos:altLabel` list for these features is long and mostly archaic exonyms, 19th-century survey spellings or close transliteration variants of each other (for example Qinghai Lake has 28 romanisations of the same two or three names; the Colorado River has over 40, mostly 19th-century survey names for stretches of it). None of that is "common alternative English names", so `aliases` is a short hand-reviewed table (`ALIASES_CURATED`), not the raw pull. Every curated alias is still checked at build time against that feature's own Wikidata English alias list (case-insensitive); the build fails if one is missing, so nothing here is invented. 21 of 101 features have a curated alias; the rest have none because no single alternative name stood out as being in everyday English use.
