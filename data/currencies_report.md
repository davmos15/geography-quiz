## Overrides applied for a country mledoze lists with no currency

- **FSM**: mledoze's FSM entry has an empty currencies object. The Federated States of Micronesia uses the US dollar under its Compact of Free Association with the United States, exactly as mledoze's own MHL (Marshall Islands) and PLW (Palau) entries already record for the other two compact-of-free-association states; USD is already a valid code in this dataset for those countries. No new source is used here -- this fills in the one country mledoze left blank with a code it already lists for its closest comparators.

## Questionable codes

Kept in the output exactly as mledoze gives them; never dropped or
silently fixed.

- **CUC**: Cuba abolished the convertible peso on 1 January 2021; mledoze's snapshot of data/source/countries.json still lists it for CUB alongside CUP. Kept, not dropped; CUP is primary for CUB (see PRIMARY_OVERRIDES).
- **SLL**: Sierra Leone redenominated its currency on 1 July 2022 (1,000 old leones = 1 new leone, new ISO code SLE, coincidentally the same three letters as Sierra Leone's cca3); mledoze's snapshot still lists only the pre-2022 SLL for SLE, and the Wikidata snapshot has no P498=SLL match either. Kept as mledoze gives it -- this pipeline only uses currencies mledoze actually lists, and does not add SLE since mledoze doesn't; flagged for the lead.

### Symbol disagreements (resolved, documented)

- **CHF**: mledoze gives 'Fr.' for Switzerland (CHE) and 'Fr' (no full stop) for Liechtenstein (LIE); kept Switzerland's as the franc's originating country.
- **EGP**: mledoze gives plain '£' for Egypt (EGY, matching how it also writes GBP) and 'E£' for the Palestinian territories' secondary use (PSE); kept Egypt's own entry.
- **JOD**: mledoze gives the Arabic symbol for Jordan (JOR, consistent with how it writes several other non-Latin-script currencies in this dataset) and the Latin abbreviation 'JD' for the Palestinian territories' secondary use (PSE); kept Jordan's own entry.
